# 鬼工厂 · Ghost Factory

> 在一间阴间工场里，用会自己干活的怪机器满足一个怪现象。
> 每只机器有一条怪癖，玩家的全部乐趣在于找到它的边界并利用它。

**设计事实来源：** [`GameDesign.md`](GameDesign.md)（v15.2，§17 是玩家视角，§18 是机械联动）。
本仓库是这份设计的**可玩垂直切片**：把最核心的那条循环做成真的能跑、能测、能扩的东西。

---

## 现在能做到什么

打开游戏先看到**开始界面**：三张夜卡（第一夜 / 第二夜 / 第三夜），每张写着波数、预算、通关奖励与漏怪上限；点哪张就直接进哪一夜。
进游戏后左键选中任何东西，左侧会弹出**数值面板**：周期 / 振幅 / 射程、机关耗能与续航、带子吞吐——所有数字都摊开，方便自己算。
选中后按 `Delete`（或点面板里的「拆除」）就能拆掉，**全额退款**；拆机关/带子时里面的晶会落到地上。
按 `Tab` 切到**幽灵视角**：站到机关之间平视它们，WASD 自由移动、右键拖动观察、Q/E 升降；再按 `Tab` 回到上帝视角。
鬼晶现在**按住就能拖**：拖到机关上松手直接插入，右键机关直接把晶取到手上，世界里有一个半透明落点预览。
手持鬼晶时，建造栏左侧会出现**手持槽**（水晶图标 + 电量条）；放下后整条消失，不会留下幽灵图标，也不会和 UI 打架。

鬼不只会「被顶立正」：**锤鬼**要被打倒才砸、**撑鬼**要靠承重才响、**摆锤鬼**要被砸一下才荡。
倒下的鬼会砸进邻格（砸脚帮它站、砸身把它推倒），撑鬼会撑住倒向它的邻鬼并算一个支撑——鬼和鬼之间真的有物理连接。

打开游戏 → 按住提示放一台顶足机关 → 把充能鬼晶插进机关 → 翘脚鬼立正 →
脉冲伤到从西边来的「魅」，同时给旁边的空鬼晶充能 → 鬼能耗尽、鬼倒下 → 换晶 → 循环。
守住第一波后会解锁第二张图纸「摆臂鬼」：它和翘脚鬼同频，摆在哪里决定了场是叠加变亮、还是互相抵消。
两只鬼一起把共振指数顶过清场线时，整片场会烧白，越线的魅被一次性抹掉——「一拱全爆」。
从第三波起会混入**甲魅**：普通脉冲只能磨掉一半血，想快就得把它拖进清场线。
准备阶段的场地信标和右侧「下一波」会提前告诉你来向、种类、数量，所以每一波都值得重新读一遍局面。
守住第二波后会解锁**搬运手**：它会把附近地上的充能晶自动换进机关，但每次搬走 1 单位鬼能——
自动化省的是注意力，手搬仍然更省能量。
最后一波会出现**魅王**：血厚、护甲高、走得很慢，抵达中央直接判负；把它拖进清场线是唯一的秒杀方式。
守住第一夜后会进入**第二夜 · 走廊**：15×9 的场地里只有三格宽的可建造带，两头来客，逼你把鬼摆成一条线。
通关面板会给一份**夜间报告**：清场流 / 磨血流、零漏、手搬 / 半自动 / 自动物流、调场师——
它不给分数，只告诉你这一夜是怎么赢的。
结算面板的「换约束重打」会轮流套上**夜规**：紧箍（预算 -30%）、孤军（没有搬运手）、催命（准备时间 -40%）。
同一张场地因此能生出不同的局。第二夜的开场会多一个「从第一夜开始」，随时能回去重打。
第一波起累计漏 10 只魅则判负，此时可一键回溯到上一波刚打完的瞬间。

**第三夜 · 大屋（v15）**：23×23 的大地图，开局只有 5×5 的领地。
每清一波，领地向外扩一圈；把东西造在领地外也行，但它会变成**越界造物**——
脚下亮红环，魅会优先来啃它，而且鬼屋每波会多刷怪。守到扩地，它就被**收编**，从此合法。
这一夜开始教**物流**：把鬼晶放上传送带，让装卸臂把它送进机关，再把空晶送回鬼屋充能——
机器会自己转起来。新鬼与机关包括**守夜钟 / 低鸣鬼 / 接力鬼 / 锚鬼 / 提灯鬼**、
**长撬 / 节拍 / 共鸣腔 / 传声筒**，以及**快带 / 装卸臂 / 引信匣**。

**内容上限证明**：`--dev-behemoth` 会在第三夜上搭出一台参考机器——四只鬼围着一台装卸臂、
节拍机关把守夜钟改成同频、共鸣腔放大、传声筒延长、两条带子往返鬼屋。
建好之后不再有任何输入，它能连续运转 60 秒：10 台机关全程有电、传送带搬 100+ 次、
清场线覆盖 179 格、漏 0 只；往清场区丢一只 800 血的厚甲魅王，同一 tick 被抹掉。
这份布局写在 `Code/Dev/Behemoth.gd`，测试 `Test_Behemoth` 每次都跑一遍。

第一次点「开始」会进入 4 步新手引导：建机关 → 插晶 → 看脉冲 → 守一波。
左上角会高亮按钮、场地里会放发光标记；不想看可以跳过，之后在帮助面板里重看。

**机器共振**：同周期的鬼在立正后会被对齐到全场节拍。三只以上同频鬼在同一拍一起发脉冲，
振幅总和越过 3.0，就会打出一发**机器共振**——大范围伤害、给地上鬼晶充能，并触发慢动作、
金色横幅和闪光。右侧「机器共振」条会实时显示蓄能；这是“整台机器一起轰鸣”的爆发点。

## 一局的完整流程

```text
第一夜 · 翘脚      四波 → 夜间报告 → [下一夜] / [换约束重打] / [从第一夜开始]
第二夜 · 走廊      四波 → 夜间报告 → [下一夜 · 大屋] / [换约束重打]
第三夜 · 大屋      六波 → 每波扩地 / 解锁 → 夜间报告 → [再守一夜]
```

三夜共用同一套规则与图纸池；第二夜把场地压成一条三格宽的走廊，第三夜把场地放大成 23×23 并开始教物流。
夜规可以在任意一夜的结算面板上换，也可以带 `--modifier=` 直接进。

## 运行

1. 用 **Godot 4.7**（开发时用的是 4.7.2-stable）打开本目录的 `project.godot`。
2. `F5` 运行。主场景是 `res://Scenes/Main.tscn`。

命令行：

```powershell
# 运行
Godot --path .

# 跑核心规则测试（退出码 0 = 全过）
Godot --headless --path . res://Code/Tests/TestRunner.tscn

# 或者一键：先 --import 注册全局类，再跑测试
tools\test.cmd D:\path\to\Godot_v4.7.2-stable_win64_console.exe

# 无头冒烟：自动放机关、插晶、跑 7 秒，打印状态
Godot --headless --path . -- --dev-smoke

# 端到端验证拖动输入（窗口模式，注入鼠标事件）
Godot --path . -- --dev-input

# 带夜规进入（调试）
Godot --path . -- --level=01 --modifier=tight

# 新手引导 / 引导状态机 / 帮助面板的截图
Godot --path . -- --dev-tutorial
Godot --path . -- --dev-tutorial-flow
Godot --path . -- --dev-help

# 机器共振的截图
Godot --path . -- --dev-resonance

# 渲染并截图到 _shots/（intro / play / duo / clear / armor / swapper / boss / wave / victory）
Godot --path . -- --dev-shot

# 第二夜（走廊）的截图
Godot --path . -- --level=02 --dev-shot2

# 第三夜（大地图）：开场小领地 + 一条物流线 + 一个越界哨站
Godot --path . -- --dev-shot3

# 内容陈列：每种鬼 / 机关 / 带子 / 臂都摆出来拍一张
Godot --path . -- --dev-gallery

# 庞然大物：在第三夜一次搭好参考机器，跑 30 秒、打印读数、截图
Godot --path . -- --dev-behemoth

# 玩家视角验收
Godot --path . -- --dev-select      # 选中 → 数值面板 → Delete 拆除
Godot --path . -- --dev-held        # 手持槽出现 / 放下后消失
Godot --path . -- --dev-eye         # 幽灵视角 + W 前进
Godot --path . -- --dev-click-card  # 点第二张夜卡 → 重载并开局

# 机械联动验收
Godot --path . -- --dev-link        # 锤鬼砸摆锤；长撬 + 撑鬼撑起锚鬼
Godot --path . -- --dev-crystal     # 拖晶进机关；右键机关取晶

# 夜规结算面板
Godot --path . -- --level=01 --modifier=tight --dev-shot-variant
```

> Windows 下建议用 **console 版**可执行文件跑测试，输出才会进管道；
> GUI 版在部分终端里不会回显 stdout。
>
> 新增带 `class_name` 的脚本后，先跑一次 `Godot --headless --path . --import`，
> 否则运行时找不到这个全局类型（`tools\test.cmd` 已经包含这一步）。

### 导出

导出到 Windows / Linux / macOS 时，记得在导出预设的
**「非资源文件过滤器」**里加上 `*.json`（Export → Resources → Filters to export
non-resource files）。否则 `Data/` 不会被装进包，启动会报内容缺失。
工程没有任何贴图 / 字体 / 音频依赖（字体走 `SystemFont`，模型全程序化），
所以导出包很小，也不需要额外授权素材。

### 操作

| 操作 | 输入 |
|---|---|
| 选中建造 | 点底部建造栏，或登记过的快捷键（`1`–`9`、`B` 带子、`N` 装卸臂、`0` 鬼晶…） |
| 放置 | 左键点格子 |
| 选中实体 | 左键点鬼 / 机关 / 传送带 / 装卸臂 → 左侧出现数值与拆除面板 |
| 拆除 | `Delete`（或面板按钮），全额退款 |
| 旋转朝向 | `R`（4 向；带子 / 臂的朝向很重要） |
| 拿 / 放鬼晶 | **按住晶拖到空地 / 机关 / 传送带，松手**；也可以点一下晶再点目标 |
| 取出插槽里的晶 | **右键机关**（或选中机关 → 面板「取出晶体」）；右键带子拿带面晶 |
| 鬼晶落点预览 | 手里有晶时，世界里会有一个半透明水晶跟着鼠标下的格子（绿=可放，红=不可放） |
| 挪位 | 按住左键拖动鬼 / 机关 / 带子 / 装卸臂到空格 |
| 取消 | 右键 / `Esc`（先清选择，再取消建造/手持） |
| 暂停 | `空格`（暂停中可建造与拆除） |
| 幽灵视角 | `Tab` / `V` 进入或返回；WASD 移动、右键拖动观察、Q/E 升降、Shift 加速 |
| 上帝视角 | `Q` / `E` 旋转，滚轮缩放，`WASD` 平移，`Home` 复位 |
| 帮助 / 重看引导 | `H`（面板底部有「重看新手引导」） |

## 为什么这样搭

- **模拟层不依赖场景树**：`Sim` 及所有 `Sim*` 都是 `RefCounted`，只吃固定 `dt`。
  所以规则能在无头环境里 480+ 项测试全部覆盖，也能整体移植到别的渲染层。
- **物理是承重的，但是确定性的**：没有用 Jolt 刚体去模拟鬼，
  而是把「翘脚 → 立正」写成单自由度倒立摆（重力矩、阻尼、脚撑、推力力矩）。
  阈值仍然来自积分出来的角度，不是脚本触发；但结果可复现、可调、可测。
- **物流是承重的**：带子单向、会堵；装卸臂有朝向、会抽成。删掉它们，参考机器会在几十秒内饿死。
- **内容数据驱动**：加一只鬼 = 加一个 JSON + `content.json` 一行；加一关 = 一个 JSON。
- **表现层只订阅事件 + 读状态**：视图不改规则，规则不认识节点。
- **存档带版本与迁移**：老档永远能读。

详细设计见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)，
设计条款的落地情况见 [`docs/DESIGN_MAPPING.md`](docs/DESIGN_MAPPING.md)，
加内容见 [`docs/CONTENT_GUIDE.md`](docs/CONTENT_GUIDE.md)。

## 技术说明

- 美术是**程序化占位**：没有贴图、没有模型资源，全部用基础网格 + 自发光 + 辉光拼出来。
  换正式美术时，只需要替换 `Code/Game/Views/` 与 `Code/UI/Palette.gd`，规则层不动。
- 存档写在 `user://save.json`；若运行环境不允许写 `user://`，会打印 warning 并继续运行。
