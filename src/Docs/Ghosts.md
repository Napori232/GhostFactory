# 鬼总表

> 每只鬼只描述**「我自己做什么」**，不描述「我和谁在一起会怎样」。
> 后者是物理层自动叠加的结果，见 `GameDesign.md` §6。
> 「类别」一列是给玩家读懂与关卡设计用的，不参与任何判定逻辑。
> 本作只有一种能量——鬼能。鬼能产出后落在地上，点一下收进守财鬼的仓储。

**移除的鬼**（随 v9 单能量改造下线）：贪食鬼、细嚼鬼（采料区无原料可采）、灶鬼（无形态可加工）、收容鬼（无垃圾可净）、供品口（计分改为累计产出）、岔口鬼（分流改为判官鬼按数量择一输出）、镜鬼（转入长期规划）。

## 2. 几何占位

每只鬼在地图上占据若干网格格，占位是**几何形状**，随放置一起对齐。

| 鬼 | 占位形状 | 备注 |
|---|---|---|
| 长舌鬼 | 1 本体 + 1 舌头附属 | 舌头附属格随朝向变化 |
| 吊死鬼 | 1 本体 + 1 吊绳附属 | 吊绳附属格随朝向变化 |
| 不倒翁鬼 | 1 格 | 最便宜的产能器 |
| 守财鬼 | 2 格（2×1） | 唯一免费的建筑 |
| 拾穗鬼 | 1 格 | 相邻 4 格吸取 |
| 判官鬼 | 2 格（2×1） | 两个输入口在两侧 |
| 感应鬼 | 1 格 | 便宜但只看邻域 |
| 线鬼 | 每经过 1 格 | 拐角格只算一次 |

## 3. 鬼的数值

〔初〕实现时全部搬进 `ExportSettings.gd`。

| 参数 | 值 |
|---|---|
| 长舌鬼 舌头周期 CD | 2.0 s |
| 长舌鬼 单次循环节拍 | 伸出 0.4s → 停留 0.3s → 收回 0.4s → 停留 0.9s |
| 吊死鬼 伸展 CD | 1.5 s |
| 不倒翁鬼 单次产鬼能 | 3 |
| 拾穗鬼 吸取间隔 / 容量 | 0.5 s / 2 |
| 判官鬼 比较延迟 | 0.3 s |
| 感应鬼 检测延迟 | 0.2 s |
| 线容量 | 3 / 段 |
| 关卡开局赠送初始鬼能 | 30 / 40 / 50（逐关） |
| 鬼的争抢优先级 priority | 逐鬼设定，同级按距离、再按放置顺序 |

## 4. 涌现出来的机关（不是规则）

以下全部是**物理层自动叠加的结果**，代码里没有对应的特判。每条只写「哪几只鬼 + 怎么摆」。

| 机关 | 怎么摆 | 为什么成立 |
|---|---|---|
| **永动机** | 长舌鬼的舌头连上吊死鬼的吊绳 | 长舌鬼自动拉取，吊死鬼自动伸展，两者互推互拉形成往复 |
| **产能链** | 长舌鬼 → 吊死鬼 → 不倒翁鬼 → 不倒翁鬼 | 推力沿链传递，不倒翁鬼被移动即产鬼能 |
| **手动产线** | 只摆吊死鬼 + 不倒翁鬼，玩家点吊死鬼 | 吊死鬼手动拉一次，不倒翁鬼被移动即产鬼能（早期关卡用） |
| **自动收集** | 拾穗鬼紧邻守财鬼与不倒翁鬼 | 拾穗鬼吸走地面鬼能并入库，仓储自动增长 |
| **分选** | 两路鬼能 → 判官鬼 → 守财鬼 | 判官鬼比较两路数量，只送多的一侧 |
| **背压** | 供给大于仓储吸收 | 缓冲与线容量有限，满了自然停 |
| **鬼能竞争** | 两只不倒翁鬼被同一段推力链交替推动 | 各自 CD 与推动顺序自然错开，产鬼能时机错开 |

**代价不是附加惩罚**，而是物理约束的必然结果：空间不够、仓储满了、鬼被抢走了——机关就是转不动。代价类型见 `GameDesign.md` §6.6。

## 5. 长期规划鬼（不进 Demo）

| 鬼 | 类别 | 独特机制 | 代价 |
|---|---|---|---|
| 鼓鬼 | 产出 | 全场鬼按节拍同时触发一次动作 | 消耗自身充能 |
| 溺鬼 | 运输 | 邻格线缆漏水，线上鬼能会流失 | 漏水范围随等级扩大 |
| 缚鬼 | 运输 | 固定相邻鬼的位置使其不能被移动 | 固定后不可再被推挤 |
| 镜鬼 | 感知 | 复制相邻鬼的端口 | 复制品产出减半、8s 后消失 |
| 甲背鬼 | 运输 | 唯一能跨越障碍传输 | 极慢，占用大量缓冲 |
