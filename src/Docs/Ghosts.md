# 鬼总表

> 每只鬼只描述**「我自己做什么」**，不描述「我和谁在一起会怎样」。
> 后者是物理层自动叠加的结果，见 `GameDesign.md` §5。
> 「类别」一列是给玩家读懂与关卡设计用的，不参与任何判定逻辑。

## 2. 几何占位

每只鬼在地图上占据若干网格格，占位是**几何形状**，随放置一起对齐。采集鬼的占位由玩家放置后框定。

| 鬼 | 占位形状 | 备注 |
|---|---|---|
| 长舌鬼 | 1 本体 + 1 舌头附属 | 舌头附属格随朝向变化 |
| 吊死鬼 | 1 本体 + 1 吊绳附属 | 吊绳附属格随朝向变化 |
| 不倒翁鬼 | 1 格 | 最便宜的产能器 |
| 灶鬼 | 2 格（2×1） | 一进一出 |
| 岔口鬼 | 2×2 四格 | 两个输出口的位置决定可接几条线 |
| 贪食鬼 | 玩家框定 | 拖动画出范围，最小 2×2 |
| 细嚼鬼 | 玩家框定 | 拖动画出范围，最小 2×2 |
| 收容鬼 | 2×2 四格 | 缓冲容量大 |
| 镜鬼 | 1 格 | 贵但省地 |
| 供品口 | 2 格（2×1） | 接收方向决定从哪侧收线 |
| 线鬼 | 每经过 1 格 | 拐角格只算一次 |

## 4. 涌现出来的机关（不是规则）

以下全部是**物理层自动叠加的结果**，代码里没有对应的特判。每条只写「哪几只鬼 + 怎么摆」。

| 机关 | 怎么摆 | 为什么成立 |
|---|---|---|
| **永动机** | 长舌鬼的舌头连上吊死鬼的吊绳 | 长舌鬼自动拉取，吊死鬼自动伸展，两者互推互拉形成往复 |
| **产能链** | 长舌鬼 → 吊死鬼 → 不倒翁鬼 → 不倒翁鬼 | 推力沿链传递，不倒翁鬼被移动即产鬼能 |
| **加工链** | 贪食鬼 → 灶鬼 → 供品口 | 采集 → 转化 → 交付，各鬼只做自己的事 |
| **形态接力** | 灶鬼 → 灶鬼 → 供品口 | 两级转化接力，Raw → Processed → 成品 |
| **分流** | 岔口鬼 → 两条支路各接一个供品口 | 岔口鬼固定 1:1 分流 |
| **采集竞争** | 两只贪食鬼框定区重叠 | 同一格掉落物被争抢，由 priority 与距离裁决 |
| **背压** | 供给大于加工 | 缓冲与线容量有限，满了自然停 |

**代价不是附加惩罚**，而是物理约束的必然结果：空间不够、材料不够、缓冲满了、鬼被抢走了——机关就是转不动。代价类型见 `GameDesign.md` §5.6。

## 5. 长期规划鬼（不进 Demo）

| 鬼 | 类别 | 独特机制 | 代价 |
|---|---|---|---|
| 鼓鬼 | 产能 | 全场鬼按节拍同时触发一次动作 | 消耗自身充能 |
| 溺鬼 | 运输 | 邻格线缆漏水，线上物料会流失 | 漏水范围随等级扩大 |
| 缚鬼 | 运输 | 固定相邻鬼的位置使其不能被移动 | 固定后不可再被推挤 |
| 算盘鬼 | 加工 | 给经过的货物记价，交付时翻倍 | 每记一次自身积攒负面状态 |
| 甲背鬼 | 运输 | 唯一能跨越障碍传输 | 极慢，占用大量缓冲 |
