## 3. 鬼的数值

| 参数 | 值 |
|---|---|
| 长舌鬼 舌头周期 CD | 2.0 s |

| 加工 yield_rate | 0.8 |
| 加工 cycle_time | 1.2 s |
| 贪食鬼 base_rate / 垃圾率 | 0.6 / 40% |
| 细嚼鬼 base_rate / 垃圾率 | 0.25 / 0% |
| 采集面积效率指数 e | 0.5 |

| 镜鬼 复制品 | 产出减半 + 8s 寿命 |
| 岔口鬼 分流比例 | 固定 1:1 |

## 4. 共鸣规则实例

每条规则 = 条件 + 效果 + 代价。代价不可省（代价类型见 `GameDesign.md` §5.3）。

| 规则 | 条件 | 效果 | 代价 |
|---|---|---|---|
| 长舌 ⇄ 吊死 | 吊死鬼已挂绳 且 位于长舌鬼舌位 | 舌头推挤吊死鬼 | 空间占用（1 格） |
| 吊死 ⇄ 不倒翁 | 吊死鬼被推动 | 不倒翁鬼连带位移 | 空间占用 |
| 不倒翁 | `MOVE` 反射 | 产鬼能 3 | 空间占用 |
| 长舌 ⇄ 灶鬼 | `GRAB` 命中 `SWALLOW` | 灶鬼吞料并转化 | 吞吐速率减半 |
| 长舌 ⇄ 镜鬼 | `MIRROR` 复制 `GRAB` | 长舌鬼与自己共鸣 | 复制品减半 + 8s |
| 灶鬼 ⇄ 岔口 | `FEED` 命中 `SWALLOW` | 支路转化 | 供品口上限 |

## 5. 长期规划鬼（不进 Demo）

| 鬼 | 动词 | 独特机制 | 代价 |
|---|---|---|---|
| 鼓鬼 | 搏动 | 全场鬼按节拍同时触发一次共鸣 | 消耗自身充能 |
| 溺鬼 | 渗漏 | 邻格线缆漏水，线上物料会流失 | 漏水范围随等级扩大 |
| 缚鬼 | 束缚 | 固定相邻鬼的位置使其不能被移动 | 固定后不可再共鸣 |
| 算盘鬼 | 增值 | 给经过的货物记价，交付时翻倍 | 每记一次自身积攒负面状态 |
| 甲背鬼 | 搬运 | 唯一能跨越障碍传输 | 极慢，占用大量缓冲 |
