## 1. 游戏概述

### 1.1 一句话

网格上的自动化建造游戏：把会自己运转的鬼摆进地图，让它们互相触发、互相供养，像搭工厂流水线一样把鬼能越造越多。

### 1.2 核心特色

市面上的自动化游戏（《沙金工业》《异星工厂》）里，机器是主角、能量是消耗品，配方解锁就是全部成长。

本作的差异：

- **鬼是规则，不是机器。** 每只鬼只有一条独特机制（长舌＝收集、镜＝复制、吊死＝吊挂）。
- **两只鬼贴在一起才会「共鸣」产鬼能。** 产线效率取决于怎么排布它们，而不是解锁了多少配方。
- **产能区是自持引擎。** 长舌鬼的舌头像 MC 活塞一样推挤一排鬼，推挤链上的不倒翁鬼持续产鬼能，不用喂料。

### 1.3 目标体验

- 前 30 秒：看懂「摆鬼 → 连线 → 它自己动」
- 前 2 分钟：发现两只鬼贴一起会来电
- 一整局：不断在「造引擎」和「造产线」之间分配有限的空间

## 2. 核心玩法

### 2.1 玩法循环

```
摆鬼 → 连线 → 鬼自动运转
              ↓
        采集区掉料 → 加工 → 供品口交付（计分）
              ↓
        产能区自转产鬼能（造更多鬼）
              ↓
        限时内达标 → 结算星级 → 解锁新鬼
```

### 2.2 玩家操作

| 操作 | 输入 | 说明 |
|---|---|---|
| 放置鬼 | 从底部鬼牌栏拖到地图 | 拖动放置 |
| 连线 | 从鬼的输出端口拖到输入端口 | 〔初〕点源端口 → 点目标端口，系统自动生成 L 形路径 |
| 触发手动鬼 | 点击该鬼 | 吊死鬼：点一下挂上吊绳 |
| 拆除 | 点击鬼或线段 | 释放占格 |
| 移动鬼 | 拖动 | 仅暂停时可拖，运行中不可 |

### 2.3 胜负条件

- **目标**：限时内交付达到 `goal_score` 份供品
- **失败**：倒计时归零且未达标，可重试，不扣任何东西
- **结算**：三轴评分（效率 / 手动 / 空间）→ 1~3 星 → 解锁新鬼

## 3. 鬼系统

### 3.1 鬼的设计原则

- 每只鬼只有 **一个** 独特机制，且要与工业化叙事自洽
- 鬼总数控制在 12~15 只，靠组合撑变化而不是靠数量
- 同一只鬼在不同邻居组合下行为不同

### 3.2 鬼一览

| 鬼 | 独特机制 | 自动/手动 | 造价 | 占格 |
|---|---|---|---|---|
| 长舌鬼 | 本体固定，舌头固定一格，像 MC 活塞按 CD 伸缩 | 自动 | 6 | 1 |
| 吊死鬼 | 点一下挂上吊绳；挂上后自动荡回 | 手动 | 5 | 1 |
| 不倒翁鬼 | 被推动就产鬼能 | 自动 | 4 | 1 |
| 灶鬼 | 按配方转化形态，带损耗 | 自动 | 8 | 1 |
| 岔口鬼 | 一分为二，固定 1:1 | 自动 | 10 | 1 |
| 贪食鬼 | 采集区：快、暴垃圾 40%、占格多 | 自动 | 12 | 区域 |
| 细嚼鬼 | 采集区：慢、不暴垃圾、占格少 | 自动 | 8 | 区域 |
| 收容鬼 | 吃垃圾腾缓冲 | 自动 | 5 | 1 |
| 镜鬼 | 复制邻居端口；复制品减半 + 8s 寿命 | 自动 | 〔初〕14 | 1 |
| 供品口 | 接受指定形态并计分 | — | 关卡预置 | 1 |
| 线 | 传输物料 | — | 〔初〕每格 1 | 每格 |

### 3.3 手动鬼

手动鬼统一为一次性开关式，不引入持续按住型——按住会让游戏变成体力活。

| 鬼 | 手动行为 | 不操作的后果 |
|---|---|---|
| 吊死鬼 | 点一下 → 挂上吊绳 | 不参与推挤链，既不被推也不中继 |

## 4. 共鸣系统

### 4.1 结构

新增一只鬼只写数据，不改核心逻辑。分三层。

**第一层 · 端口（开放词表，有方向）**

| 方向 | 含义 |
|---|---|
| ACTION | 我能作用于什么（施加方） |
| RECEPTACLE | 我能被什么作用（承受方） |

鬼 A 的 ACTION 端口命中邻居的 RECEPTACLE 端口即触发。一只鬼可以有多个端口、多种方向。

已用标签：`GRAB` 攫取 / `HANG` 悬挂 / `SWALLOW` 吞噬 / `FEED` 投喂 / `SPLIT` 分流 / `MIRROR` 复制 / `OFFER` 交付。

**第二层 · 反射（条件句）**

`当 [事件] 发生于我 → 执行 [效果]`

| 事件 | 触发时机 | 用它的鬼 |
|---|---|---|
| MOVE | 自身位置发生变化 | 不倒翁鬼、吊死鬼 |
| ACTED_ON | 自己被别人作用 | 通用 |
| BUFFER_FULL / BUFFER_EMPTY | 缓冲满 / 空 | 收容鬼 |
| NEIGHBOR_CHANGED | 邻居变化 | 镜鬼 |
| TICK | 每秒 | 通用 |

反射层让「不需要对手」的鬼成立：不倒翁鬼的规则是「我被移动 → 我产鬼能」，纯自身状态。

**第三层 · 场域**

采集鬼占据矩形区域，区域内产生掉落物，从输出端口送出。

### 4.2 触发规则

共鸣不需要冷却，条件本身就是门槛。

| 条件 | 含义 |
|---|---|
| ON_ACTION_DONE | 触发者完成一次动作（如舌头伸出一次） |
| ON_ENTER_CELL | 触发者移动到指定相邻格 |
| ON_STATE | 触发者进入某状态 |
| COMPOSITE | 多条件同时满足 |

机制：条件满足 → 结算 → 条件重置，需再次满足才能再次触发。

CD 就是限流器：舌头每 2s 伸一次，条件自然只满足一次。

共鸣分两类：自持型（靠自身 CD，产能区）、物流型（靠物料供给，加工与分流）。

### 4.3 代价

每条共鸣规则必须附带至少一项代价。

| 代价 | 说明 |
|---|---|
| 空间占用 | 产能区与产线抢同一份预算 |
| 产出打折 | 共鸣期间 ×0.5 |
| 产生垃圾 | 产出的一部分变垃圾，堵缓冲 |
| 寿命限制 | N 秒后强制解除 |
| 占位 | 共鸣中的鬼不能再与别的鬼共鸣 |
| 反向效果 | 一增一减 |

## 5. 产能区

### 5.1 推挤链

长舌鬼的舌头推挤链上的鬼，推力沿链连锁传递。

```
长舌鬼 ──推──▶ 吊死鬼 ──推──▶ 不倒翁鬼 ──推──▶ 不倒翁鬼
                (中继)        产鬼能 3          产鬼能 3
```

- 舌头伸出 → 推前方一格 → 缩回时把抓住的鬼拖回一格
- 推拽免费，不需要任何物料
- 吊死鬼自动荡回（`HANG` 端口自作用），玩家只负责第一次挂绳

### 5.2 产能公式

```
一次循环产出 = 链上不倒翁鬼数 × 3
产能速率     = 链上不倒翁鬼数 ÷ 舌头 CD（〔初〕2.0s）
```

### 5.3 取舍

| 想更多鬼能 | 代价 |
|---|---|
| 链上多塞不倒翁鬼 | 多占格子，挤掉产线空间 |
| 缩短舌头 CD | 速率更高但节奏更密 |
| 加吊死鬼当传力者 | 多占 1 格，链条才能继续往后延 |

### 5.4 循环节拍

〔初〕单次循环 2.0s：伸出 0.4s → 停留 0.3s → 收回 0.4s → 停留 0.9s。

## 6. 物流系统

### 6.1 线

线也是鬼，有方向、有容量。

| 项 | 规则 |
|---|---|
| 走向 | 正交折线，不斜 |
| 方向 | 输出端口 → 输入端口，不可反向 |
| 容量 | 〔初〕每段 3 个物品 |
| 移动 | 离散格步进，每 〔初〕0.3s 前进一格，不用插值 |

不用连续插值是因为整个游戏是「一次一次像机关」的节奏，插值与网格对不齐。

### 6.2 缓冲与背压

每只鬼有输入缓冲与输出缓冲，容量按鬼不同。

背压连锁（自动发生，不需要玩家干预）：

```
输出缓冲满 → 停止收上游 → 输入缓冲满 → 停止从上线取货
→ 线满(3) → 上游鬼输出缓冲满 → 继续往上游传 → 采集区吸不走料，掉落物堆积
```

玩家应对：重排布局、减少上游供给、或加收容鬼清垃圾。

〔初〕缓冲容量：采集鬼输出 3 / 灶鬼 3:3 / 岔口鬼 3:3 / 供品口输入 6 / 长舌鬼输出 2 / 收容鬼 4。

### 6.3 掉落物与垃圾

两者都是真实实体，占据格子。数值上均无上限，不会因为太多而卡死。

视觉上限只是表现层的堆叠压缩：同格最多画 5 个图标，超出转 `×N` 角标，底层数值完全准确。

玩家必须能看出哪里堵了：

| 信号 | 表现 |
|---|---|
| 缓冲满 | 鬼身脉冲警示 |
| 线满 | 线段上物品变红闪烁 |
| 采集区堆积 | 堆叠高度上升 |

### 6.4 垃圾处理

收容鬼吃垃圾，释放被占的缓冲。〔初〕处理速度 1 个 / 2.0s，每吃 1 个返 1 鬼能。

## 7. 采集系统

### 7.1 采集区

采集区形状自由，玩家可拖出任意形状。形状和面积是两个独立决策：

| | 影响 |
|---|---|
| 形状 | 掉落点覆盖到哪 |
| 面积 | 总掉落量 |

〔初〕总掉落率 = `base_rate × area^0.5`（边际递减，不是越大越好）。

| 面积 | 4 格 | 9 格 | 16 格 |
|---|---|---|---|
| 总率（base 0.5） | 1.0/s | 1.5/s | 2.0/s |
| 每格效率 | 0.25 | 0.167 | 0.125 |

形状对总量无影响——否则自由形状只是绘制自由，没有决策价值。

### 7.2 两个变体

| | 贪食鬼 | 细嚼鬼 |
|---|---|---|
| 形状 | 自由 | 自由 |
| 基础掉落率 | 〔初〕0.6 | 〔初〕0.25 |
| 垃圾率 | 40% | 0% |
| 建造造价 | 12 | 8 |

### 7.3 掉落触发

| 触发源 | 用于 | 效果 |
|---|---|---|
| 时间轮询 | 采集鬼 | 区域内随机位置掉一个料 |
| 动作触发 | 节点鬼 | 完成一次有效动作掉一个料 |

## 8. 资源与形态

### 8.1 鬼能

全局唯一的硬货币，用于建造鬼与线。来源只有产能区。

### 8.2 形态

物品按关卡定义的形态流转。每一关的形态、配方、交付物、地图都不同，全是关卡级数据。

| 概念 | 说明 |
|---|---|
| 形态 Form | 物品类别标签，全局词表、关卡引用 |
| 配方 Recipe | 形态→形态的转换，只能由配方决定 |
| 供品口 | 接受指定形态并计分 |

### 8.3 加工与损耗

加工带损耗，差额变垃圾。〔初〕yield_rate 0.8，cycle_time 1.2s。

垃圾因此是全系统效率的残渣：堵缓冲 → 背压 → 逼玩家重排。

UI 必须显示「输入 5 / 产出 4 / 损耗 1」。

### 8.4 形态分流

岔口鬼比例固定 1:1，不可调。改变某条支路的形态靠在该支路上放加工鬼。

```
          ┌→ 供品口 A（收 Raw）
料源 → 岔口 ┤
          └→ 供品口 B（收 Processed，经加工鬼转换）
```

## 9. 地图与空间

### 9.1 地图

地图是预先设计好的固定小网格，含地形与障碍。玩家在既定地图里布置鬼和线，不能改变地形。

〔待〕地图尺寸逐关设计时定。

### 9.2 空间预算

| 项 | 规则 |
|---|---|
| 节点鬼 | 占 1 格 |
| 采集鬼 | 占其采集区实际格数 |
| 线 | 每经过 1 格占 1 格，拐角格只算一次 |

线的占位是空间管理的核心：一条绕远的线吃掉 6 格，就少放 6 只鬼。

〔初〕空间预算逐关收紧：12 / 18 / 24 格。

### 9.3 两套经济

| | 产出 | 来源 | 瓶颈 | 用途 |
|---|---|---|---|---|
| 鬼能线 | 鬼能 | 产能区（自持引擎） | 链长 ÷ 舌头 CD | 造鬼、造线 |
| 交付线 | 供品（计分） | 采集 → 加工 → 供品口 | 缓冲容量 | 达成关卡目标 |

产能区不产供品，交付线不产鬼能。每一格空间都要在这两条线之间分配。

如果只有一条经济线，玩家只有一个优化方向，很快会腻。两条线各有独立瓶颈，才有「先扩哪边」的取舍。

## 10. 关卡

### 10.1 难度设计

难度按概念递增，不按数值递增。

| 章 | 新增概念 |
|---|---|
| 1 | 放置、连线、吞吐、交付 |
| 2 | 形态、配方、损耗、垃圾、背压 |
| 3 | 产能区、推挤链、空间取舍 |
| 4 | 岔口鬼、镜鬼 |
| 5 | 多目标、严限时、窄地形 |

### 10.2 Demo 三关

| 关 | 时长 | 教什么 | 引入 |
|---|---|---|---|
| 1 | 90s | 纯输送：拖放、连线、自动运转、交付 | 长舌鬼、供品口 |
| 2 | 120s | 加工：形态转换、损耗、垃圾、背压 | 灶鬼、贪食鬼、收容鬼 |
| 3 | 120s | 产能区 + 形态分流 | 岔口鬼、吊死鬼、不倒翁鬼 |

镜鬼与细嚼鬼挪到后续章节。

### 10.3 评分

| 轴 | 含义 | 引导 |
|---|---|---|
| 效率 | 单位时间交付量 | 造线紧凑 |
| 手动 | 所需点击次数 | 优化组合而非硬点 |
| 空间 | 占用格数 / 可用格数 | 做取舍而非铺满 |

1★ 达标 / 2★ 基准时间 / 3★ 三轴同时达标。

### 10.4 关卡数据结构

```
Data/Levels/Level01.tres
  forms_used: [Raw]           recipes_in_use: []
  terminals: [{accepts: Raw, position: (9,5), score: 1}]
  fields:    [{shape: [...], drops: Raw, interval: 1.0, garbage_rate: 0.4}]
  obstacles: [...]            space_budget: 12
  time_limit: 90              goal_score: 20
  available_ghosts: [LongTongue, Terminal]
```

新增关卡 = 加一个 .tres，零代码改动。

### 10.5 元进度

局外层是解锁表，每关通过后自动解锁下一项。无货币、无攒点。

| 解锁项 | 作用 | 何时 |
|---|---|---|
| 新鬼 | 可放置的新规则单元 | 主体 |
| 新形态 | 关卡可用的物品形态 | 第 2 关 |
| 新配方 | 形态转换规则 | 第 2 关 |
| 新机制 | 如槽位可解锁、线可升级 | 后期 |

关卡必须声明可用鬼池白名单，防止解锁的鬼带来超纲配方。

不做局外货币——它会引入「这局多刷点」的元游戏，与产线专注度冲突。

## 11. 教程

形式为对话框 + 聚光灯遮罩（周围变黑，中间标亮目标）。

- `CanvasLayer` + 全屏半透明黑 `ColorRect` + 挖亮区（Shader 或 `Light2D`）
- 亮区跟随目标世界坐标实时更新
- 流程：点继续 → 亮区移到下一目标 → 完成操作 → 对话框继续
- 内容与关卡数据绑定，不硬编码在 UI 脚本里
- 教程期间游戏暂停

只教四件事：拖放、连线、点手动鬼、交付。

## 12. 存档与设置

### 12.1 存档

`user://savegame.cfg`，完整存档。

| 段 | 内容 |
|---|---|
| version | 存档版本号，用于迁移 |
| progress | 已解锁关卡、每关最佳星级、当前所在关 |
| unlocked_ghosts / forms / recipes | 已解锁内容 |
| settings | 音量、教程跳过、震动、画质 |
| meta | 累计游玩时长、通关次数 |

- 实体用 `ExportSaveData() -> Dictionary` / `LoadSaveData(data) -> void` 序列化
- 关卡中途退出不保存（关卡内状态是瞬态），只存进度与设置
- 音量沿用现有 `user://audio_settings.cfg`（`Util.gd` 已实现），不重复造
- 写入时机：解锁新鬼 / 关卡结算 / 设置变更 / 退出游戏

### 12.2 设置

| 项 | 说明 |
|---|---|
| 音量 × 5 | Master / Music / SFX / Dialogue / Ambience，实时生效 + 持久化 |
| 跳过教程段落 | 已看过的段落不再重复 |
| 屏幕震动 | 开关 |
| 特效质量 | 低 / 中 / 高 |
| 重置进度 | 二次确认 |

音量走 `Util.SetAudioVolume` / `GetAudioVolume`，总线已配。

### 15.3 运行循环

逻辑与渲染分离，逻辑固定 20 Hz，每 tick 按固定顺序执行：

```
1. 采集掉落    采集区按轮询率生成掉落物
2. 鬼动作      推进 CD 到期的鬼（舌头伸缩、吞吐、分流）
3. 位移结算    推挤链的连锁位移，逐个结算 MOVE 反射
4. 共鸣判定    端口匹配 + 条件检查，结算共鸣与代价
5. 物流推进    物品步进一格，背压自上游向下游传播
6. 加工/交付   加工转化（计损耗）、供品口接收计分
7. 缓冲/垃圾   BUFFER_FULL 等触发反射
8. UI 刷新     资源条、警示、倒计时
```

顺序不可交换：先动作后位移（舌头推人产生位移），先位移后共鸣（位移触发反射），先共鸣后物流。

暂停条件：打开设置 / 教程对话框显示 / 〔待〕规划模式。暂停保留全部状态。

### 15.4 规范

遵循 `src/AGENTS.md`：

- 公共方法 PascalCase + `##` 文档注释，内部方法 `_snake_case`
- 跨实体通信一律走 SignalBus，不直接调用别的方法
- 数值全部导出到 `ExportSettings.gd`
- `class_name` 只在 `Common/` 声明
