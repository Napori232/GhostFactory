# 鬼工厂 · 游戏设计

在一间格子化的阴间工厂里摆出会自己干活的鬼，把鬼能变成贡品——限时、限地、限量交付。

---

## 1. 世界观

主角在原本的世界里一直打工，最后猝死了。

死后他发现自己家在阴间有一间工厂——美美当资本家。

要当资本家就得有人替他干活，所以他雇了一个假小子秘书鬼当左膀右臂，同时兼任新人引导。

---

## 2. 游戏概述

### 2.1 一句话

在格子化的阴间工厂里摆出会自己干活的鬼，让它们联动起来，把鬼能变成贡品，限时、限地、限量交付。

### 2.2 呈现形态

工厂是一块有厚度的地台，鬼是有体积的实体，掉落物散在地面上，连线贴地连通各台机器。玩家从斜上方俯看整块地台，可以把视角按 45° 一档转到八个方位，从任意一侧检查产线。

俯仰固定、旋转吸附到档位、地面始终完整可读，格子不会因远近变形。转视角是为了看清被挡住的机器和线路，不是为了探索空间。

---

## 3. 核心玩法

### 3.1 玩法循环

```
放置鬼（花鬼能） → 接端口 → 运行
        ↓
生产按周期产出鬼能，掉在旁边随机空格
        ↓
采集在框选范围内一格一格搜过去，在相邻格拾起掉落物
        ↓
送仓库（= 建造货币） 或 送处理（= 贡品原料）
        ↓
处理成贡品，损耗出杂质；杂质占格，要再处理
        ↓
贡品送进交付口 → 限时内交够数 → 结算
```

**第 1 关为教学简化**：没有仓库口、没有处理环节，手动拾起的鬼能直接送进交付口计分。

### 3.2 玩家操作

| 操作 | 输入 | 说明 |
|---|---|---|
| 放置鬼 | 从底部鬼牌栏拖到地图，可以改变方向 | 消耗全局鬼能池；**未放置前刚体 / 柔体都可自由拖动预览**；放下即固定 |
| 调整采集范围 | 拖拽采集鬼的边角手柄 | 框一个矩形，决定它的搜索区域；超软上限有步进惩罚（§7.2） |
| 接线 | 从输出端口拖到输入端口 | 有向；自动生成正交折线路径；空间不够则拒绝 |
| 切换状态 | 点击鬼本体 | 待机 / 运行 / 暂停 三态循环切换 |
| **拆除** | **选中鬼后按 `Delete` / 工具栏拆除按钮** | 释放占格，全额退还鬼能；点击鬼本体**不再**触发拆除 |
| 手动拾取 | 点击资源拖拽 | 收进全局鬼能池（顶部资源条）；第 1 关也可直接把地面掉落物拖到交付口 |
| 交付 | 把物品拖到交付口，或点交付口 | 从地面 / 鬼能池送 1 件进交付口，按关卡指定的目标形态计分 |
| 复制 | 选择一部分鬼 | 释放自动复制 |

**玩家永远不能拖动已经放下的鬼**，不论刚体柔体、不论运行还是暂停。放置阶段的拖拽是「摆放」；放下之后柔体只会**被其他机关推动 / 挤开**（§4.4、§8.3），那是物理联动，不是玩家操作。想改已放下的布局，只能拆除后重放。

**点击鬼只切状态**；拆除走 `Delete` 键与工具栏按钮，界面上给出明确按键提示。

### 3.2.1 视角操作

| 操作 | 输入 | 说明 |
|---|---|---|
| 旋转视角 | `Q` / `E`，或右键拖拽 | 按 45° 一档吸附到八个方位 |
| 缩放 | 滚轮 | 三档视野（近 / 中 / 远） |
| 平移 | `WASD` / 中键拖拽 | 限制在地台边界内 |
| 聚焦 | `F` | 把选中的鬼移到画面中心 |
| 复位 | `Home` / 界面按钮 | 回到该关预设的初始朝向与缩放档 |
| 透视查看 | 按住 `Alt` | 建筑半透，只留地面格、连线与端口，用来在遮挡时布线 |

**视角操作不消耗时间、不影响关卡进行、不计入评分的「手动」轴。** 限时关卡里转视角不会暂停或加速模拟；暂停时也可以自由转视角查看布局。

### 3.3 胜负条件

- **目标**：限时内把 **N 个目标形态的物品**送进交付口（第 1 关是鬼能，第 2 / 3 关是贡品）
- **失败**：倒计时归零且未达标；可重试，不扣任何东西（关卡内不存档）
- **结算**：三轴评分（效率 / 手动 / 空间）→ 1~3 星 → 解锁新鬼

## 4. 系统一：鬼

### 4.1 定义与三条描述轴

**鬼就是一台台机器。** 每只鬼独立占格，有输入输出端口，有自己的行为。

一只鬼由三条轴描述，三条轴互相独立：

| 轴 | 取值 | 作用 |
|---|---|---|
| **大类** | 生产 / 采集 / 处理 / 运输 | 决定它干什么活 |
| **触发类型** | 自动 / 被动 / 检验后 | 决定它什么时候动 |
| **可动性** | 刚体 / 柔体 | 决定它能不能被推、能不能被拖动 |

**四个大类是分类，不是鬼**，只给玩家和关卡设计读，不参与任何判定；具体有哪些鬼见 `Ghosts.md`。三条轴的组合产生具体行为，但**描述轴不是判定开关**：同类鬼相接不会触发「同类加成」，发生什么由物理联动算出来（§8）。

### 4.2 四个大类

| 大类 | 干什么 | 有输入吗 | 有输出吗 | 典型形态 |
|---|---|---|---|---|
| **生产** | 按周期凭空产出鬼能，掉在自身旁边的随机空格 | 无 | 无（产出直接落地） | 鬼能 |
| **采集** | 在框选范围内一格一格搜，把掉落物拾进输出区 | 无（拾取对象来自地面） | 有 | 鬼能 / 杂质 |
| **运输** | 沿已连的路径把一件东西搬到下一台机器 | 有 | 有 | 原样搬运 |
| **处理** | 把输入的东西加工成贡品，按损耗产出杂质 | 有 | 有 | 鬼能 → 贡品；杂质 → 回收鬼能 |

**端口数量允许为 0。** 生产的输入对象是地面掉落物而非管道里的东西；端口的方向语义不变：有输入端、有输出端。

**生产只产鬼能。**「用产出的鬼能再造一台生产机器」是玩家的行为，不是第二种产出。

### 4.3 触发类型

| 类型 | 何时动 | 含义 |
|---|---|---|
| **自动触发** | 按自己的周期动 | 机器自带节奏与 CD，不变 |
| **被动触发** | 被别的鬼影响时才动 | 被推动、被挡住、被撞击后才有反应 |
| **检验后触发** | 检验物理层的变化后才继续 | 产出先落到待检状态，检验合格才生效或计分 |

**检验后触发是通用机制**，给特定鬼设置即可：任何一只鬼都可以被标为检验后触发，含义统一为「它做出来的东西要先过检验才算数」。

**检验由交付口执行**，检验对象是送到的物品：合格 → 计分；不合格 → 转为杂质。杂质因此有了合法来源——它是「不合格但没消失的产物」，不污染关卡目标，却会占格。

### 4.4 可动性与拖拽

| 属性 | 定义 | 后果 |
|---|---|---|
| **刚体** | 放下之后不可动 | 推不动、挤不走；位置永久固定 |
| **柔体** | 放下之后可动 | 会被推动链带动、会互相挤开；自身行为也可以包含位移 |

| 阶段 | 刚体 | 柔体 | 谁在动 |
|---|---|---|---|
| **未放置前**（放置预览） | 玩家可自由拖动 | 玩家可自由拖动 | 玩家操作 |
| **放置以后** | 完全不可动 | 只能被其他机关推动 / 挤开 | **不是玩家操作**，是物理联动 |

- 玩家**任何时候都不能拖动已经放下的鬼**，不论刚体柔体、不论运行还是暂停
- 柔体的「可动」**只指被机关推动**（推动链、挤压），不是玩家拖动；被推离原设计位就是布局失误的代价
- 想改已放下的布局，只能拆除（全额退还）后重放；**暂停也不能拖**

**放置前可自由预览占位**，拆除全额退还鬼能——试错成本要低，玩家才敢摆复杂产线。

### 4.5 状态机

| 状态 | 含义 | 玩家可切换 |
|---|---|---|
| **待机** | 放好但没开工 | ✓ |
| **运行** | 正在干活 | ✓ |
| **暂停** | 临时按住，停工但保状态 | ✓ |
| **故障** | 因条件不满足而停摆 | ✗（由条件触发） |

**待机 / 运行 / 暂停 点击循环切换**：待机 → 运行 → 暂停 → 待机。

**故障的进入条件**（任一满足）：

- 输出缓冲满且无下游可去（下游缓冲也满）
- 处理缺料且等待超时
- 采集的搜索区被完全堵死（掉落物四邻格全部不可达）
- 掉落的鬼能无处可落（四邻无空格且自身缓冲满）

**故障由玩家手动点击恢复**：点击该鬼 → 回到待机。自动恢复会让玩家失去「我在修机器」的存在感，因此不做自动恢复。

**状态与在制品**：切到待机或暂停时，加工中的半成品保留在输入区里，不消失、不返还。

### 4.6 参数

| 参数 | 含义 | 单位 |
|---|---|---|
| **速度** | 移动一格所需时间 | 秒 / 格（越小越快） |
| **处理时间** | 完成一次作业所需时间 | 秒 / 次 |
| **输入容量** | 输入区能存几件 | 件 |
| **输出容量** | 输出区能存几件 | 件 |

参数的适用随大类变化：

| 大类 | 速度 | 处理时间 | 输入容量 | 输出容量 |
|---|---|---|---|---|
| 生产 | — | 生产周期 | — | ✓ |
| 采集 | 搜索步进 | 拾取耗时 | — | ✓ |
| 运输 | ✓ | — | ✓ | ✓ |
| 处理 | — | ✓ | ✓ | ✓ |

**生产周期就是它的处理时间**，不再单开参数。**运行时零消耗**：鬼工作时不耗鬼能，只有建造花鬼能。

### 4.7 端口

每只鬼有输入端口与输出端口，可以有多个，**数量允许为 0**。端口是接入点，不是触发开关。

- 玩家从输出端口拉到输入端口，自动生成正交折线路径
- 路径每经过一格占一格，拐角格只算一次
- 空间不够则拒绝接线并给出提示
- 端口不兼容（例如产线物料与目标形态对不上）在放下瞬间就拒绝，不静默失败

**接线的是「通路」，不是「规则」。** 接上之后鬼能怎么流、机器之间怎么互相影响，由物理联动与各鬼自身行为算出。

端口的**朝向以世界方位为准**（东 / 南 / 西 / 北），不随视角旋转改变；界面上的端口标记始终朝向玩家，避免转到背面时认不出接口。

### 4.8 输入区 / 输出区与交互口

#### 4.8.1 输入区与输出区都对应到格子

所有物料流转都是**格到格**的，不存在悬空的抽象容器：

- 每台鬼的**输入区**与**输出区**都绑定到明确的格子（端口格 / 缓冲格），位置由占位形状与朝向决定
- 「输入容量 / 输出容量」是**件数**，但这些东西落在对应的格子上；缓冲满 = 该格堆满
- 采集在掉落物**四邻格之一**拾取（§7.3）→ 拾起后放进自己的**输出格**
- 运输把一件东西从上游**输出格**搬到下游**输入格**；连线每经过一格占一格
- 掉落物与杂质各占 1 格，是流转的起点与终点，不是额外的容器层

#### 4.8.2 交互口

关卡预置的「交付口 / 仓库口」是**同一类可配置的设施**，行为由关卡决定，不是每种口各是一套规则：

| 设施 | 行为 | 接收形态 | 出现关卡 |
|---|---|---|---|
| **交付口（鬼能）** | 检验并计分 | 鬼能 | **第 1 关（唯一设施）** |
| **交付口（贡品）** | 检验并计分，不合格转杂质 | 贡品 | 第 2 / 3 关 |
| **仓库口** | 接收鬼能，转为建造货币 | 鬼能 | 第 2 / 3 关 |

- **第 1 关没有仓库口**，只有一个接收鬼能的交付口
- 目标形态由关卡指定、交付口由关卡指定接收形态，两者一致才计分；**增加一种交付形态不需要新增一种设施**
- 端口标签不匹配时在接线瞬间就拒绝，不静默失败
- 设施是关卡预置的，玩家不能移动也不能拆除

## 5. 系统二：世界、空间与视角

### 5.1 格子

世界是方格的。每一格有明确归属：空地、鬼占位、掉落物、杂质、障碍。

- 鬼按**几何形状**占位（直线、L 形、T 形、多格不规则），**形状由关卡设计与鬼的大类决定，占格总数是形状的结果**
- 掉落物与杂质各占 1 格；同格可堆叠，视觉上最多画 5 个图标，超出转 `×N`，底层数值准确
- 掉落物占格不可通行，柔体鬼不能穿过掉落物

采集不需要进入掉落物所在格，在四邻格之一即可拾取（§7.3），因此本条与拾取不冲突。

### 5.2 有限空间

**空间预算就是这一关「可放置区域」的面积（格数）。** 它是关卡划定的一块或几块、玩家可以把鬼放上去的格子集合，**不是**「最多能占多少格」的上限，也**不是**整张网格的面积。

| 消耗方 | 说明 |
|---|---|
| 鬼占位 | 几何形状的面积，落在可放置区里 |
| 线路 | 每经过一格占一格 |
| **掉落物与杂质** | 掉在地上就是占格，不捡走就一直占着，会挤掉可放置区里的可用位置 |

- 可放置区面积：Demo 三关为 **18 / 22 / 26 格**
- 关卡网格（10×8 / 12×9 / 14×10）是**地台尺寸**；可放置区是其中被划出来的一部分，区外格子不可放鬼
- **预置设施与障碍不计入**可放置区面积
- 评分「空间」轴 = 已用可放置格 / 可放置区面积（§9.3），引导是「做出取舍而不是铺满」

**地面占用是本作最狠的约束之一**：生产一直在掉东西，处理一直在掉杂质。地面堵了，采集就搜不到路，鬼就进故障。

### 5.3 掉落规则

生产每完成一次生产，在**自身四邻的空格中随机一格**掉落 1 单位鬼能。

- **四邻均匀**：四个方向等概率，看哪里有空位置就掉哪
- 四邻无空格 → 产出进入自己的输出区
- 缓冲满 → 故障
- 掉落位置随机 → 采集必须真的去找，这正是「搜索区大小」成为决策的原因

**摆放生产机器的位置就是在设计掉落分布**：让它贴着搜索区边缘放，掉落大多落在区内。四邻方向按世界方位定义，与视角朝向无关。

### 5.4 视角

| 项 | 规定 |
|---|---|
| 视角 | 斜俯视，俯仰角固定，八个方位按 45° 一档吸附旋转 |
| 缩放 | 三档视野：8 / 12 / 16 格高 |
| 平移 | 限制在地台边界内 |
| 初始朝向 | 每关预设，保证交付口与可放置区一眼同屏 |
| 朝向提示 | 界面常驻八向罗盘，标出当前方位与世界北 |

**视角不进玩法**：旋转 / 缩放 / 平移不改变任何格坐标、连线、搜索区、掉落分布、联动结果；不暂停游戏、不消耗关卡时间、不产生任何游戏事件。

### 5.5 操作优先级

多个操作共用鼠标，按以下顺序判定：

```
1. 视角操作（右键拖拽 / 中键拖拽 / 滚轮）
2. 端口拖拽 → 接线
3. 采集范围边角手柄拖拽 → 调整范围
4. 从鬼牌栏拖出 → 放置鬼
5. 鬼本体点击 → 切换状态
6. 掉落物点击拖拽 → 手动拾取
7. `Delete` / 工具栏按钮 → 拆除选中的鬼
```

按住 `Alt` 只改变显示，不屏蔽操作。

### 5.6 遮挡与可读性

3D 建筑必然互相遮挡，规则是：

| 手段 | 说明 |
|---|---|
| 八向旋转（主手段） | 转到能看清的一侧 |
| 建筑高度上限 | 所有鬼模型与障碍墙 ≤ 1 格高，禁止高墙整片遮住地面 |
| 选中描边 | 被选中 / 悬停的鬼显示轮廓，即使被挡住也能看到位置与形状 |
| 拾取规则 | 只命中最前面的可见实体；被完全遮挡的实体不能点，需转视角或用透视查看 |
| 透视查看 | 建筑半透，地面格线、连线、端口、掉落物保持不透明 |
| 状态浮标 | 状态与故障标记始终朝向玩家，任何角度都能读 |

**遮挡只影响可见性与点选，不影响逻辑。** 被挡住的照常运行、照常掉落、照常进故障。

### 5.7 单层平面

**逻辑世界是单层平面网格**，3D 只是把这张平面立起来看：

- 没有高度层、没有立体堆叠、没有跨层输送
- 建筑模型的高度只影响遮挡与观感，**不参与占格、寻路、推动链、碰撞、搜索的任何判定**
- 视角转到哪个方向，格坐标、连线、搜索区、掉落分布都完全一样

### 5.8 视觉表现要求

| 元素 | 要求 |
|---|---|
| 地台 | 有厚度，表面画格线；可放置区高亮，区外明显压暗 |
| 鬼 | 有体积，状态用灯色与浮标区分；选中时描边 |
| 掉落物 / 杂质 | 落在格中心，堆叠超 5 个转 `×N` 标记 |
| 连线 | 贴地、清晰可辨，不与地面重叠到分不清；拐角共格只算一次 |
| 端口 | 标记始终朝向玩家，标出输入 / 输出与世界方位 |
| 采集范围框 | 贴地矩形，四角手柄可拖，旋转视角后仍能框准 |
| 障碍 | ≤ 1 格高，带明显顶面轮廓，不与空地混淆 |
| 状态提示 | 待机 / 运行 / 暂停 / 故障四种状态在八个方位下都可读 |

## 6. 系统三：鬼能经济

### 6.1 一份鬼能，两个去处

鬼能既是**建造货币**也是**加工原料**，而且是同一种东西。这是本作经济设计的核心张力。

| 去处 | 路径 | 意义 |
|---|---|---|
| **鬼能池 / 仓库** | 手动拾取或采集 → 全局鬼能池；第 2 关起可送仓库口 | 转成建造本钱，扩大产能 |
| **交付** | 鬼能直接交付（第 1 关）或加工成贡品后交付（第 2 / 3 关） | 转成关卡目标 |

**同一堆掉落物只能走一条路。** 拿去建鬼就少一份贡品，反之亦然。玩家的每一个决定都是「我要钱还是要命」。

不把鬼能拆成两种资源，而是让**同一实体有两个去向**，取舍由玩家做，不靠数值平衡。

**第 1 关没有仓库口**：手动拾起的鬼能直接进全局鬼能池（界面上的资源条），既当建造本钱，也可以直接送进交付口计分。取舍仍然存在，但不需要额外的设施。

**仓库是调控杠杆**：第 2 关起，仓库口是建造货币的入口，容量上限与接收速率由关卡指定。仓库**进多去少** → 很快满 → 顶住上游生产 → 玩家被迫把一部分掉落物分流去加工。难度与关卡节奏靠这个旋钮调。

### 6.2 形态与配方

形态是全局词表，关卡引用；转换只能由配方决定。

| 形态 | 来源 | 去向 |
|---|---|---|
| **鬼能** | 生产掉落 | 鬼能池 / 仓库 / 处理 |
| **贡品** | 处理加工产出 | 交付口（检验后计分） |
| **杂质** | 处理损耗产出 | 地面占格；可被采集拾起，再送处理做**再处理** |

**再处理不会再生杂质**：处理杂质时**全额回收鬼能**，且不再掉杂质。这是让系统收敛、也让再处理值得占用机器位的关键一条。

**关卡目标只有单一形态**。第 1 关是鬼能，第 2 / 3 关是贡品；多形态目标留到后续章节。

### 6.3 损耗

处理不是无损的：

- 每加工 4 件产出 1 件杂质（损耗率 25%）
- 杂质不污染关卡目标，但它占格
- 不清理杂质，地面会被慢慢吃满

**清理杂质的成本是玩家自己的时间或机器位数**——没有免费的垃圾处理。

### 6.4 生产与货币

- 建造消耗鬼能池里的鬼能；拆除**全额退还**，鼓励试错重排
- 每关开局赠送初始鬼能，保证玩家开局能摆出第一条链
- 运行时零消耗

## 7. 系统四：收集

### 7.1 搜索

采集的搜索范围是玩家框选的一块**矩形区域**。

- 采集**一格一格地搜**，路径由深度优先（DFS）求解：先沿一条方向走到尽头，再逐条回退换方向
- 搜索区越大，需要遍历的格子越多，找到掉落物的平均耗时越长
- 搜索区越小 → 搜得快，但可能覆盖不到随机落点

遍历顺序按格子定义，与视角朝向无关。

### 7.2 范围博弈

掉落位置随机，搜索成本随面积增长。玩家因此面对三个同时成立的取舍：

| 想 | 代价 |
|---|---|
| 搜索区小 → 搜得快 | 覆盖不全，落点在区外就永远找不到 |
| 搜索区大 → 覆盖全 | 每找一件都要多走很多格，吞吐下降 |
| 多个采集分头搜 | 占用更多格子与更贵的机器 |

**摆放生产机器的位置本身就是在设计掉落分布**：让它贴着搜索区边缘放，掉落大多落在区内。

**软上限 + 步进惩罚**：不设硬上限，玩家想框多大都行；但超过软上限后，每多 1 格都会拖慢搜索步进。

| 参数 | 值 |
|---|---|
| 软上限 | 9 格（3×3） |
| 基础搜索步进 | 0.1 s / 格 |
| 超出惩罚 | 每超 1 格，步进 +10% |

```
实际步进 = 0.1 × (1 + max(0, 面积 - 9) × 0.10)     秒 / 格
```

4×4 = 16 格 → 0.17 s / 格；5×5 = 25 格 → 0.26 s / 格。大搜索区仍能覆盖更多随机落点，但遍历成本上升，玩家自己权衡「覆盖」与「吞吐」。**惩罚只改步进耗时**，不改遍历顺序、不改空间预算。关卡可以用推荐值引导（教学关推荐 3×3），超限时在范围框上显示当前步进。

### 7.3 拾取

采集走到掉落物的**四邻格之一**（上 / 右 / 下 / 左）即可拾取，不必进入该格。

```
走到掉落物四邻格 → 拾取（0.5 秒 / 件）
  → 放进自己的输出格（§4.8）→ 沿连线送到下游输入格
```

- 四邻格都不可达（被鬼 / 杂质 / 障碍占住）→ 该掉落物本轮取不到，采集继续搜索
- 输出区满 → 停止拾取（背压）
- 搜索区内没有任何掉落物 → 空跑，持续消耗时间

## 8. 系统五：物理联动

### 8.1 原则

**鬼的行为只描述「我自己做什么」，不描述「我和谁在一起会怎样」。**

几只鬼摆在一起会发生什么，是**物理联动**的结果，不是写下来的规则。因此不设组合规则表，也不列举「哪几只摆成什么形状会怎样」——那是玩家自己发现的东西，写死就变成了白名单：没写到的组合大半无效。

### 8.2 位移的结算单位

物理是连续的，格子是离散的。**本作以格为位移的最小结算单位**：所有推动、挤压、行走的结果都以「一格」为单位落地，动画负责把这一格铺得顺。

**分工**：联动决定**谁动了谁、谁挡路**；DFS 决定采集的**搜索顺序与步数**；格子决定**动到哪里停下**。

### 8.3 推动链

被动触发的柔体被推一下 → 撞到前方的柔体 → 推力沿链传递。

- 链上每被推动一次，就发生一次该鬼自己的反应（产出、掉落、加工）
- 刚体在链上是**止点**：推力到刚体为止，刚体不动
- 链长不是参数，是玩家摆出来的几何结果；接不上就断

### 8.4 代价

代价不是额外贴上去的惩罚，是约束的自然结果：

| 代价 | 来源 |
|---|---|
| 空间不足 | 机器、线、掉落物、杂质抢同一份格子 |
| 背压 | 缓冲与线路容量有限，满了就停 |
| 损耗 | 加工必然掉杂质 |
| 随机 | 掉落位置随机，找不到就空跑 |
| 碰撞 | 柔体会被挤开，被挤到就偏离原设计位 |

### 8.5 视角与联动

推动链在平面上结算，推力方向按世界四邻定义，**与视角朝向无关**。遮挡不阻断联动：被挡住的鬼照常参与全部结算。位移仍以一格落地，动画负责把这一格铺顺。

## 9. 关卡

### 9.1 难度设计

按概念递增，不按数值递增。每关只加一个新维度。

| 关 | 新增概念 |
|---|---|
| 1 | 放置、运行状态、掉落、手动拾取、交付、建造消耗 |
| 2 | 采集与搜索区范围、连线输送、背压 |
| 3 | 处理、加工、杂质占格、产能与交付抢空间 |

### 9.2 Demo 三关

| 关 | 时限 | 目标 | 目标形态 | 可放置区 | 设施 | 教什么 |
|---|---|---|---|---|---|---|
| 1 | 90 s | **30 个鬼能** | 鬼能 | 18 格 | **只有 1 个交付口（鬼能）** | 放置、运行、掉落、手动拾取、交付、建造消耗 |
| 2 | 120 s | **72 个贡品** | 贡品 | 22 格 | 交付口（贡品）+ 仓库口 | 采集范围、连线输送、背压 |
| 3 | 120 s | **55 个贡品** + 不超 3 个杂质残留 | 贡品 | 26 格 | 交付口（贡品）+ 仓库口 | 加工损耗、杂质清理、产能与交付抢空间 |

**第 1 关**：不设仓库口，地图上只有 **1 个接收鬼能的交付口**。玩家手动拾起地面鬼能 → 收进全局鬼能池 → 送进交付口计分；也可以把地面掉落物直接拖到交付口。同一份鬼能拿去交付就少一份建造本钱，**取舍仍在**。目标形态与交付口接收形态都由关卡指定，两者一致才计分。

### 9.3 评分

| 轴 | 含义 | 引导 |
|---|---|---|
| 效率 | 单位时间交付目标形态物品数 | 缩小搜索区、缩短线路 |
| 手动 | 所需点击次数 | 用采集替代手捡 |
| 空间 | 已用可放置格 / 可放置区面积 | 做出取舍而不是铺满 |

1★ 达标 / 2★ 基准时间 / 3★ 三轴同时达标。基准时间与三轴阈值待实机校准：

| 关 | 2★ 基准时间 | 3★ 参考（效率 / 手动 / 空间） |
|---|---|---|
| 1 | ≤ 75 s | 30 个 / ≤ 75 次点击 / 用 ≤ 12 格 |
| 2 | ≤ 100 s | 72 个 / ≤ 60 次点击 / 用 ≤ 16 格 |
| 3 | ≤ 105 s | 55 个 / ≤ 45 次点击 / 用 ≤ 20 格 |

**视角操作不计入「手动」轴的点击次数**：转视角是为了看清，不是玩法操作。

### 9.4 关卡配置

每关需要指定的内容：

| 项 | 说明 |
|---|---|
| 开局鬼能 | 保证玩家能摆出第一条链 |
| 目标数量 / 目标形态 | 两者一起决定这一关要交什么 |
| 时限 / 2★ 基准时间 | |
| 可放置区 | 明确列出哪些格可以放鬼，面积即空间预算 |
| 障碍 | 位置与形状 |
| 设施 | 每个交互口的类型（交付 / 仓库）与接收形态、位置、朝向 |
| 可用鬼白名单 | 防止解锁的鬼带来超纲规则 |
| 初始视角 | 开场朝向与缩放档，只影响观感 |

目标形态必须与交付口的接收形态一致，不一致时关卡不成立。

### 9.5 元进度

局外层是解锁表，每关通过后自动解锁新鬼与新机制，无货币、无攒点。关卡必须声明可用鬼白名单。

### 9.6 关卡的视觉约束

| 约束 | 理由 |
|---|---|
| 每关指定初始视角，让交付口与可放置区同时可见 | 第一眼就能看懂「在这摆、往那送」 |
| 障碍墙 ≤ 1 格高、带可辨识顶面 | 防止斜俯视下整片地面被遮住 |
| 预置设施带固定世界朝向与高对比标识 | 转视角后仍能分辨交付口 / 仓库口，以及交付口接收的形态 |
| 连线贴地、不与地面重叠到分不清 | 保证八个角度都读得出线路走向 |
| 可放置区高亮画在地面 | 旋转后仍严丝合缝贴在格上 |

## 10. 教程

### 10.1 形式

秘书鬼的对话框 + 聚光灯遮罩（周围变暗，中间标亮目标）。

- 遮罩在界面层，亮区跟随目标位置实时更新
- 3D 目标额外加发光描边 / 上浮箭头，避免只有屏幕挖洞时玩家找不到立体对象
- 流程：点继续 → 亮区移到下一目标 → 完成操作 → 对话框继续
- 教程期间游戏暂停

### 10.2 教学范围

只教五件事：放置、切换运行、拾取掉落物、建造消耗、连线。

第 1 关结尾留一个 5 秒的互动信号（推动演示 + 掉落 + 秘书鬼一句吐槽），让玩家第一次看到两只鬼联动。

开场用一行提示告诉玩家可以按 `Q` / `E` 转视角。它不算教程步骤、不暂停游戏、不计入教学进度。

### 10.3 秘书鬼

- 定位：主角的秘书兼左膀右臂，新人引导者
- 性格：假小子，嘴硬爱吐槽，但干活利落
- 台词方向：毒舌不刻薄，讲效率讲规矩，不卖萌
