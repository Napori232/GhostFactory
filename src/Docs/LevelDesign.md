# 鬼工厂 · Demo 三关设计

> 面向 5 分钟展示。三关总时长 **330 秒（5 分 30 秒）**。
> 玩家操作：放置机关、切换运行、接线、拾取掉落物、花鬼能建造。
> 本案以 `GameDesign.md`（v10）为准；v9 的关卡设计（供品口 / 采集区 / 形态）已作废。

---

### 预置内容

| 类型 | 位置 | 说明 |
|---|---|---|
| 仓库口 | (1,4)，朝东 | 接收鬼能，转为建造货币 |
| 贡品口 | (8,4)，朝西 | 检验并计分 |
| 障碍 | (4,1)(5,1)(6,1) | 3 格墙，逼玩家绕线与摆位 |

### 玩家要做的事

1. 放 2 只生产鬼，点一下让它们进入运行
2. 每 2.0s 每只产 1 单位鬼能，掉在四邻随机空格
3. 点地面鬼能 → 进仓库（仓库里就是建造本钱）
4. 再放第 3、4 只生产鬼，扩大产出
5. 仓库鬼能凑够后，把鬼能送进贡品口（仓库口 → 贡品口要接线？**否**，见下）

**关卡 1 的简化处理**：本关不引入采集鬼与运输鬼，**玩家必须手动把鬼能从仓库口搬到贡品口**（点仓库口旁的「取出」→ 点贡品口）。这让玩家亲手建立「产出 → 存储 → 交付」的因果感，也把手动作做成后续要优化的对象。

### 吞吐核对

- 产出速率：2 只生产鬼 × 1 / 2.0s = **1.0 /s**
- 手动拾取 + 搬运速度：假设玩家 1.0 次点击 / 1.2s ≈ **0.83 /s**（略慢于产出 → 逼迫玩家加机器）
- 90s × 0.83 ≈ **74 个**，远超目标 12 → 目标留足余量给首次上手

**为什么目标定 12**：玩家第一次上手要经历「放鬼 → 切运行 → 看掉落 → 点拾取 → 送交付」的完整学习曲线。90 秒里前 40 秒基本在摸索，12 个的达成时间约 15~20 秒，留足失败重来的空间。

### 空间核对

- 4 只生产鬼 = 4 格
- 仓库口 1 + 贡品口 1（预置，是否计入预算见 `GameDesign.md` §17）
- 掉落物零散占格，10 只以内
- 合计 ≈ 6 格 ≤ 18，余量充足（第一关不讲空间）

### 预置内容

| 类型 | 位置 | 说明 |
|---|---|---|
| 仓库口 | (1,7)，朝东 | |
| 贡品口 | (10,2)，朝西 | 与仓库口对角，逼玩家拉长线路 |
| 障碍 | (5,3)(5,4)(5,5)(6,3)(6,4) | 中央 5 格墙，切断直线通路 |

### 玩家要做的事

1. 放 3 只生产鬼，集中在地图左下
2. 放 1 只采集鬼，**框选**一块区域覆盖生产鬼的四邻（3×3）
3. 采集鬼输出 → 运输鬼 → 贡品口，或采集鬼输出 → 仓库口
4. 手动拾取的量减少 → 体验「自动化替代手捡」

### 吞吐核对

- 产出：3 只生产鬼 = **1.5 /s**
- 采集：搜索区 9 格，DFS 逐格 0.1s，找到掉落物平均需遍历约 4.5 格 = 0.45s + 拾取 0.5s ≈ **0.95s/件 → 1.05 /s**
  → **采集鬼是瓶颈**：产出 1.5/s 但只能采 1.05/s
- 要追上产出需要第 2 只采集鬼 → 但空间预算与机器位要算 → 教学点：**不是无脑加机器，是缩小搜索区或集中掉落**
- 若把生产鬼围在 3×3 内（掉落必然落在区内），采集鬼的有效搜索区缩到 4 格 → 约 **0.9s/件 → 1.1 /s**，仍需 2 只采集鬼
- 120s × 1.05 ≈ **126 个** ≥ 目标 18 → 达成约 17 秒，余量充足

### 空间核对

- 3 生产鬼 3 + 2 采集鬼 2 + 2 运输鬼 2 + 线约 8 = **15 格 ≤ 22**

### 预置内容

| 类型 | 位置 | 说明 |
|---|---|---|
| 仓库口 | (1,8) | 建机器要花钱，仓库口是唯一的收入口 |
| 贡品口 | (12,2) | 接收加工后的贡品 |
| 障碍 | (6,2)(6,3)(6,4)(7,2)(7,3)(7,4)(6,5)(7,5) | 中央 8 格大墙 |

### 玩家要做的事

**两条线，抢同一份鬼能**

1. 产能线：生产鬼 → 采集鬼 → **仓库口**（换成建造本钱）
2. 交付线：生产鬼 → 采集鬼 → 处理鬼 → **贡品口**
3. 两边抢同一批掉落物：送去仓库就少一份贡品
4. 处理鬼产出 25% 杂质，杂质占格；要么加一只采集鬼专门收杂质送去再处理，要么容忍残留（目标限 ≤ 3）

### 吞吐核对

- 4 只生产鬼 = **2.0 /s**
- 采集：4 格有效搜索区 ≈ 1.1 /s（每只）；需 2 只采集鬼分别服务两条线 = 2.2 /s
- 处理：处理时间 1.2s → **0.83 /s**，产出 1 贡品 + 25% 杂质
  → **处理鬼是瓶颈**：0.83 贡品/s
- 120s × 0.83 ≈ **100 个** ≥ 目标 20 → 达成约 24 秒
- 杂质产生：0.83 × 0.25 ≈ **0.21 /s** → 120s 约 25 件杂质；若不清理，25 格占位远超 26 格预算的余量 → **必须清理**
- 清理路径：采集鬼收杂质 → 处理鬼再处理（1.6s，回收 1 鬼能，不再产杂质）
  → 需要第 3 只采集鬼，或让一只采集鬼兼顾两种目标（成本：吞吐下降）

### 空间核对

- 4 生产鬼 4 + 3 采集鬼 3 + 2 处理鬼 4 + 运输鬼 2 + 线约 12 = **25 格 ≤ 26**，几乎用满

## 待实机调整

- 三关的地图都留了大片空白，是给玩家自由布线的空间；实际关卡场景里障碍物要加 2~3 块，否则「空间取舍」不存在
- 采集鬼的框选交互与放置操作可能冲突，实机需要验证手势优先级
- 第 3 关的双线分配是最复杂的一关，如果实机跑不通，可先砍掉杂质清理要求，只留加工与损耗
